# Document PDF Compiler

Local-first browser utility untuk menyusun dan menggabungkan dokumen kepada satu PDF akhir.

Susunan utama:

VSO → IC → LESEN → PAYSLIP → BANK STATEMENT → OTHER

Semua dokumen diproses di browser. Tiada database dan tiada upload dokumen customer ke backend aplikasi.

## Deploy

Repository ini disediakan untuk static hosting di Vercel. Import repository ini ke Vercel dan deploy menggunakan tetapan default / Other framework.
