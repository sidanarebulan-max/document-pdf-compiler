Share dari iPhone — setup sekali

iPhone tidak mendaftarkan web app ini sebagai penerima fail terus dalam menu Share. Gunakan Apple Shortcut Hantar ke FARIS. Shortcut menerima fail, menyimpannya dalam Fail Masuk, kemudian membuka ruang Dokumen.

Jika belum mahu setup Shortcut: WhatsApp → Share → Save to Files, kemudian tekan Muat Naik Fail di atas dan pilih dokumen tersebut.

Buka panduan untuk semak kunci akaun.

Kunci hanya boleh menghantar fail. Tamat selepas 90 hari; ganti atau nyahaktif di sini. Jangan kongsi Shortcut yang masih mengandungi kunci akaun anda.

  1. Buka aplikasi Shortcuts pada iPhone, tekan +, namakan Hantar ke FARIS. Dalam Details, hidupkan Show in Share Sheet dan terima Files / PDFs / Images.
  2. Tambah tindakan Repeat with Each. Input: Shortcut Input.
  3. Dalam Repeat, tambah Get Contents of URL. Salin URL di bawah. Method: POST.
  4. Dalam Headers, tambah X-Faris-Upload-Key. Nilainya: kunci yang dijana di atas. Jangan gunakan passcode staf.
  5. Request Body: Form. Tambah medan jenis File, nama medan file, nilai Repeat Item. Jangan isi Content-Type sendiri; Shortcuts akan menetapkannya.
  6. Tambah Get Dictionary Value untuk kunci ok daripada hasil Get Contents of URL. Tambah If: jika nilainya tidak benar, Show Alert “Fail tidak berjaya dihantar” dan Stop This Shortcut. Tutup If dan Repeat.
  7. Selepas End Repeat, tambah URL dengan pautan Dokumen di bawah, kemudian Open URLs.
  8. Di WhatsApp, buka dokumen → Share → Hantar ke FARIS. Benarkan Shortcut menghubungi server apabila diminta kali pertama. Dokumen akan disimpan, kemudian ruang Dokumen dibuka. Log masuk jika diminta.
